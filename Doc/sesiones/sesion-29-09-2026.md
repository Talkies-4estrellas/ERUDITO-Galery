### 1. `database/fix_orphaned_obras.sql` — limpieza de obras huérfanas

**Problema:** Al eliminar artistas del catálogo (`DELETE FROM artistas`), sus obras quedaban con `id_artista = NULL` (ON DELETE SET NULL) sin `artista_email`, apareciendo en el home y catálogo como obras sin dueño.

**Fix:**
- Elimina obras donde `id_artista IS NULL AND artista_email IS NULL AND empresa_email IS NULL`
- Pobla `nombre_artista` con el nombre real del usuario para obras de maestros mexicanos
- Sube `vistas` escalonadas (200→155) para que los maestros mexicanos dominen el carousel

```sql
DELETE FROM obras
WHERE id_artista IS NULL
  AND (artista_email IS NULL OR artista_email = '')
  AND (empresa_email IS NULL OR empresa_email = '');

UPDATE obras o SET nombre_artista = u.nombre FROM usuarios u
WHERE o.artista_email = u.email AND (o.nombre_artista IS NULL OR o.nombre_artista = '');

UPDATE obras SET vistas = 200 WHERE artista_email = 'davidsiqueiros@gmail.com' AND estado = 'aprobada';
-- (y así para los 7 maestros restantes en orden descendente)
```

### 3. `lib/db.ts` — filtro para excluir obras sin artista y fix de IDs

**Problema A:** `getCarousel()`, `getFichas()` y `getFichasNuevas()` mostraban obras huérfanas incluso después del DELETE, porque el filtro `estado='aprobada'` no era suficiente.

**Fix:** Añadido `.or("id_artista.not.is.null,artista_email.not.is.null")` a las tres funciones.

**Problema B:** Los artistas de plataforma aparecían con "0 obras" en su tarjeta de la listing, porque `mapUsuarioArtista` asignaba IDs negativos secuenciales (-1, -2, …) mientras que `mapFicha` asignaba `id = 0` a todas las obras de plataforma — nunca coincidían.

**Fix — función `emailToId()`:** Hash determinista del email que produce el mismo entero negativo siempre, usado tanto en `mapUsuarioArtista` como en el else-branch de `mapFicha`:

```ts
function emailToId(email: string): number {
  let h = 5381;
  for (let i = 0; i < email.length; i++) h = ((h << 5) + h + email.charCodeAt(i)) | 0;
  return h >= 0 ? -(h + 1) : h;
}
```

**Problema C:** Carlos Ramírez y Diego Rivera (cuentas de prueba) aparecían en la listing de artistas aunque no tenían obras aprobadas.

**Fix:** `getArtistas()` ahora filtra artistas de plataforma cruzando contra un query de `artista_email` con obras aprobadas:

```ts
const emailsConObras = new Set((dataObrasEmails ?? []).map((r) => r.artista_email));
const artistasPlataforma = (dataUsuarios ?? [])
  .filter((row) => emailsConObras.has(row.email))
  .map(mapUsuarioArtista);
```
