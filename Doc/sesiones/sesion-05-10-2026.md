## Notas técnicas de la sesión
- Dev server siempre en `localhost:3000` — **no iniciar nuevo**
- Turbopack acumula errores de compilaciones previas en consola del browser — verificar con screenshot o `document.title`, no con `read_console_messages`
- Paginación JSX: los controles deben colocarse FUERA del ternario principal como expresión hermana `{condicion && (...)}`, no dentro de una rama del ternario sin wrapper
- `elementFromPoint` retorna null en coordenadas fuera del viewport — la "N" del browser pane es UI de Claude Code, no del app
- Error de SQL: `fecha::date + INTERVAL + ::text` falla en columna `timestamp` — usar `fecha + INTERVAL '4 months'` directamente
