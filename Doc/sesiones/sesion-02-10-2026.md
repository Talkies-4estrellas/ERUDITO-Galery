## Lo que se hizo

### 1. `components/FichaObra.tsx` — Rediseño completo de la tarjeta

**Cambio principal:** La información de la obra (título, año, estrellas, descripción, tags, precio) se movió del hover externo a un overlay de tres capas dentro de la imagen, visible siempre.

**Tres capas de overlay (dentro del `<Link>`):**
- **Capa 1 (z-[8])**: Gradiente base `from-zinc-500/90 via-zinc-400/50 to-transparent` — relleno de color gris
- **Capa 2 (z-[9])**: `backdrop-blur-sm` con `mask-image: linear-gradient(to top, black 40%, transparent 100%)` — blur que se desvanece hacia arriba sin borde visible
- **Capa 3 (z-10)**: Texto (título, año, estrellas, descripción, tags, precio ámbar)

Todas las capas tienen `pointer-events-none` excepto la capa de texto, para que los clics lleguen al `<Link>`.

**Zoom de imagen:** Cambiado de estado (`hovered ? "scale-105" : ""`) a CSS puro `group-hover:scale-105`.

### 2. `components/FichaObra.tsx` — Tooltip pegado a CapsulaArtista

**Concepto:** El tooltip flotante (descripción ampliada) ya no se dispara al hacer hover en toda la tarjeta, sino exclusivamente al interactuar con la `CapsulaArtista`. Esto lo hace parecer que "pertenece" a la cápsula.

**`capsulaRef`**: `useRef<HTMLDivElement>` añadido junto a `artRef`. La función `mostrar()` lee `capsulaRef.current.getBoundingClientRect()` para posicionar el tooltip exactamente bajo la cápsula.

**Wrapper de la cápsula:**
```tsx
<div
  ref={capsulaRef}
  className="mt-3 cursor-pointer"
  onMouseEnter={mostrar}
  onMouseLeave={ocultar}
  onClick={handleTap}
>
  <CapsulaArtista artista={ficha.artista} />
</div>
```

El `article` ya no tiene ningún handler de mouse.

### 3. `components/FichaObra.tsx` — Bug de tooltip en móvil (mouseleave sintético)

**Problema:** En táctil, al levantar el dedo, el navegador dispara un evento `mouseleave` sintético que llama a `ocultar()` e inmediatamente oculta el tooltip recién mostrado.

**Fix — función `ocultar()`:**
```tsx
const ocultar = useCallback(() => {
  if (window.matchMedia("(hover: none)").matches) return;
  hideRef.current = setTimeout(() => {
    setHovered(false);
    setCardRect(null);
  }, 80);
}, []);
```

**Función `cerrar()` separada** (cierre forzado para scroll, backdrop y `handleTap`):
```tsx
const cerrar = useCallback(() => {
  if (hideRef.current) clearTimeout(hideRef.current);
  setHovered(false);
  setCardRect(null);
}, []);
```

`handleTap` usa `cerrar()` (no `ocultar()`) para cerrar el tooltip de forma inmediata al tocar de nuevo.

### 4. `components/FichaObra.tsx` — Posición exacta del tooltip en móvil

**Problema:** Las tarjetas tienen ancho fijo `w-60` en scroll horizontal. El cálculo de centering + clamping desplazaba el tooltip hacia la izquierda de la tarjeta tocada.

**Fix:** En móvil (`vw < 640`), el tooltip usa exactamente las dimensiones del `cardRect` sin clamping:
```tsx
if (vw < 640) {
  return {
    position: "fixed" as const,
    left: cardRect.left,
    top: cardRect.bottom + 4,
    width: cardRect.width,
    maxHeight: vh - cardRect.bottom - 16,
    overflowY: "auto" as const,
    zIndex: 9999,
  };
}
```

Aunque el tooltip pueda quedar cortado lateralmente si la tarjeta está en el borde del scroll, respeta exactamente la posición de la tarjeta correspondiente.

### 5. `components/Carousel.tsx` — Tarjeta de info separada en móvil

**Problema:** La tarjeta de información del carrusel (overlay `absolute bottom-6 left-6`) cubría la imagen en móvil donde el aspect-ratio 16/9 solo da ~211px de altura.

**Fix:**
- Desktop: `hidden sm:block absolute bottom-6 left-6 max-w-md` — overlay original solo en sm+
- Móvil: `sm:hidden mt-3 rounded-xl bg-zinc-900/95 px-4 py-3.5 ring-1 ring-white/10` — tarjeta separada debajo de la imagen

### 6. `components/FichaObra.tsx` — Difuminado gris suave

**Requerimiento:** Las imágenes deben tener un gradiente gris difuminado en la parte inferior, como en la imagen de referencia, sin que se note un borde visible donde empieza el blur.

**Solución (tres capas explicadas arriba):**
- El blur (`backdrop-blur-sm`) usa `mask-image` para desvanecerse gradualmente
- El gradiente tiene color `zinc-500/90` (gris medio) en la base para parecerse más a la referencia
- La altura del blur es 72% de la tarjeta con el mask iniciando opaco desde el 40% inferior

---

### 7. `components/BarraNavInferior.tsx` — Nueva barra de navegación flotante para móvil

**Nuevo componente** `"use client"` con detección de ruta activa:

```tsx
const ITEMS = [
  { href: "/",          label: "Home",      icon: "ti-home" },
  { href: "/catalogo",  label: "Catálogo",  icon: "ti-layout-grid" },
  { href: "/artistas",  label: "Artistas",  icon: "ti-palette" },
  { href: "/perfil",    label: "Perfil",    icon: "ti-user" },
];
```

- Solo visible en móvil: `sm:hidden fixed bottom-4 inset-x-3 z-50`
- Forma de píldora: `rounded-3xl border border-white/10 bg-zinc-950/80 backdrop-blur-xl shadow-2xl`
- Ítem activo: `bg-amber-400/15 text-amber-400`; inactivo: `text-zinc-500`
- Detección de activo: `href === "/" ? pathname === "/" : pathname.startsWith(href)`
- Iconos Tabler Icons webfont (cargados vía CDN en `app/layout.tsx`)

---

### 8. `app/layout.tsx` — Registro global de BarraNavInferior

Para que la barra aparezca en **todas las páginas**, se añadió en el layout raíz:

```tsx
import BarraNavInferior from "@/components/BarraNavInferior";
// ...
<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@tabler/icons-webfont@latest/tabler-icons.min.css" />
</head>
// ...
<body className="min-h-full flex flex-col pb-24 sm:pb-0">
  {/* ... */}
  <ToastProvider>
    {children}
    <Footer />
    <BarraNavInferior />
  </ToastProvider>
</body>
```

El `pb-24 sm:pb-0` en el `body` evita que el contenido quede tapado por la barra en móvil.
